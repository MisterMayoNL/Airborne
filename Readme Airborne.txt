Airborne adds more chaos and craziness to vanilla Company of Heroes, without changing the core gameplay or feel.
The vanilla grittiness with new wackiness!
(This mod is made by someone who both plays very little RTS as is terrible at playing them)

"Balance? Who cares about balance?!" ~Joey

=====================================================================
COMPATIBILITY
=====================================================================

This mod is only compatible with the PC/Steam version of Company of Heroes (V2.700.2.43).
Only English is supported.
Should work with friends if they also download this mod.


=====================================================================
INSTALLATION
=====================================================================

)1. Place all other items in this zip in your root CoH1 folder (Steam\steamapps\common\Company of Heroes Relaunch)
)2. Run the Airborne.BAT (or first run AirborneRefreshRate.BAT if you have a refresh rate higher than 60)

You're done!
REMEMBER TO SCROLL IN THE VICTORY CONDITION SETTING IN SKIRMISH!!!

*It is recommended to enable subtitles, as some characters are named differently then what is said during cutscenes.


[Optional] Enabling native language for Axis (reverse step 4 to disable it again):
)1. Download & install German Axis voices (https://www.moddb.com/mods/company-of-heroes-airborne/addons/native-german-voices)
)2. Open Airborne.module using notepad (Company of Heroes Relaunch folder)
)3. Search for [data:english:02] (Ctrl+F)
)4. Remove the -- in front of the archives with 'German' at the end and arrange the numbers accordingly (so 1 to 12)



If you're interested in the development history of this mod, you can check out the changelog in Airborne\Archives (does not include the first year of development).
